# Welcome to GirlScript Summer of Code 2026

GirlScript Summer of Code is India's largest builder program for developers, students, and AI creators - a free, non-profit open-source initiative by GirlScript Foundation, running since 2018. Now in our 7th edition, GSSoC has grown to 50,000+ applicants and a community of 500,000+ members worldwide.

Throughout the program, participants contribute to real-world projects under the guidance of experienced mentors, earn points based on contribution quality, and build a public track record on GitHub that actually matters. Top contributors receive certificates, swag, and featured recognition from GirlScript Foundation.

### Program Tracks

GSSoC'26 runs two tracks - both free, both open to everyone:

- **Open Source Track** - Contribute to curated open-source repositories. Fix bugs, add features, improve docs, write tests. Points are earned based on the difficulty and quality of your merged PRs.
- **Agents for India Track** - Build real-world AI agents that solve India-specific problems, powered by Smartly Labs.

## Point System

Every merged PR gets reviewed and labeled by maintainers. Your final score is:

> **Base + (Difficulty × Quality Multiplier) + Type Bonus**

| Component | Label | Value |
|-----------|-------|-------|
| Base | `gssoc:approved` | +50 pts |
| Difficulty | `level:beginner` | 20 pts |
| | `level:intermediate` | 35 pts |
| | `level:advanced` | 55 pts |
| | `level:critical` | 80 pts |
| Quality Multiplier | `quality:clean` | ×1.2 |
| | `quality:exceptional` | ×1.5 |
| Type Bonus | `type:docs` | +5 pts |
| | `type:testing` / `type:design` / `type:refactor` / `type:bug` / `type:feature` | +10 pts |
| | `type:accessibility` / `type:performance` / `type:devops` | +15 pts |
| | `type:security` | +20 pts |
